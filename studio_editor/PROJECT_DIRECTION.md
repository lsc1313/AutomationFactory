# Studio Editor 기능 확장 원칙 (2026-11-17)

**새 제품으로 갈아엎는 것이 아니라 기존 AI 편집기 위에 정밀 편집 기능을 추가한다.**

현재의 핵심 AI 워크플로(사진/영상 업로드 → 요구사항·스타일·음성·음악 설정 → AI 분석·영상 기획·대사·자막·장면 초안 → 사용자 수정 → MP4 생성)를 **전부 보존**한다. 기존 AI 기능을 수동 편집으로 대체하지 않는다.

새로 추가할 내용은 영상 트리밍/분할/삭제/반복/복제/길이 조절, 원본 오디오 유지, 별도 자막·음성·배경음악 트랙, 가로/세로/정사각 출력, 긴 영상 요약·짧은 영상 확장이다. AI 자동 초안 생성 결과가 상세 타임라인에서 편집 가능해야 한다.

설계·구현 시 기능 제거는 금지하고, 기존 프로젝트를 보존한다. 구현 전후로 AI 초안 생성 및 기존 MP4 내보내기의 회귀 테스트를 통과해야 한다.
