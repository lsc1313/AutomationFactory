# Studio Editor — 범용 비파괴 영상 편집기 제품 명세 (2026-11-17)

> **제품 정의:** 사진과 기존 영상을 자유롭게 편집하는 무료·로컬 우선 영상 편집기. AI는 **선택형 편집 보조**이며 영상 픽셀을 새로 생성하는 유료 AI 비디오 생성 서비스는 필수 기능이 아니다.

## 0. 현재 구현과 목표의 차이

현재 v0.4.x는 **장면(sequence of stills/full videos)** 기반이다. 업로드한 동영상은 전체 파일이 반복/루프되고, 클립의 시작/끝 지점을 지정하는 트리밍과 원본 오디오 보존이 없다. 프로젝트는 9:16 720×1280 고정 출력이고, 한 장면당 하나의 자막이다. 사진을 업로드한 뒤 사용자가 장면으로 배치하거나 AI 초안을 적용할 수 있다. 완전한 CapCut/Vrew 편집기라고 부르면 안 된다.

목표는 **실제 시간 기반 다중 트랙 타임라인**이다. 사진/영상/텍스트/음성/음악 클립을 각기 독립적으로 편집하며, 원본 파일을 다시 인코딩하거나 잘라 저장하지 않는 비파괴 편집을 기본으로 한다.

## 1. 반드시 되는 이용 사례

| 목적 | 편집 흐름 | 특별 요구 |
|---|---|---|
| 사진 광고 | 사진 업로드 → 선택/순서/시간 → 자막/대본/TTS/BGM → MP4 | AI 선택적 |
| 영상 광고 | 영상 일부 구간 추출 → 재배열 → 오디오 선택 → 카피/자막 | 원본 오디오 유지 옵션 |
| 사진 영상 | 사진에 지속시간, 팬/줌, 전환, 텍스트와 BGM | 원본 영상 불필요 |
| 기존 영상 편집 | 가져오기 → 자르기/분할/삭제 → 자막·텍스트 → 출력 | 원본 음성 유지 기본 |
| 긴 영상 짧게 | 범위 선택·분할 → 불필요한 클립 삭제 → 화면비/재프레이밍 | 지정한 구간만 사용 |
| 짧은 영상 길게 | 동일 클립 반복·복제, 사진 삽입, 속도 조절, 정지 프레임 | 반복 횟수·총길이 표시 |
| ASMR/힐링 | 원본 오디오 유지 → 선택적으로 자막/BGM | AI 보이스 기본 꺼짐 |
| 여러 동영상 합치기 | 복수 비디오/오디오를 순서대로 배열·연결 | FPS·음량·해상도 통일 |
| 녹음 영상 | 원본 음성의 STT → 단어/문장 자막 → 수정 | STT는 선택형 추가 설치 |
| 무성영상 | 소리 없이 자막·전환·움직임만 | 불필요한 음성 자동 생성 금지 |

## 2. 편집기 핵심 데이터 모델

자산(media assets)과 편집 클립(timeline clips)을 명확히 분리한다.

```json
{
  "schemaVersion": 2,
  "project": {
    "id": "stable-id",
    "title": "Example",
    "canvas": {"width": 1080, "height": 1920, "fps": 30},
    "tracks": [
      {"id": "v1", "kind": "visual", "clips": [
        {"id": "c1", "mediaId": "assetA", "timelineStartMs": 0, "sourceInMs": 3000, "sourceOutMs": 9000, "playbackRate": 1, "volume": 1, "repeats": 1, "transform": {"scale": 1, "x": 0, "y": 0}}
      ]},
      {"id": "t1", "kind": "text", "clips": []},
      {"id": "a1", "kind": "source-audio", "clips": []},
      {"id": "a2", "kind": "narration", "clips": []},
      {"id": "a3", "kind": "music", "clips": []}
    ]
  }
}
```

- 모든 시간 계산은 밀리초로 한다. 클립 길이 = (sourceOutMs − sourceInMs) × repeats ÷ playbackRate.
- 사진 자산의 sourceIn/Out은 없고 각 클립에서 durationMs로 길이 관리.
- 장면을 나눌 때 소스 파일은 **절대 수정하지 않는다**. 분할 클립 두 개의 sourceIn/Out만 바꾼다.
- 같은 자산을 여러 클립에서 재사용한다. 복제 및 반복에 원본을 추가로 업로드하지 않는다.
- 트랙별 mute/solo/volume, 독립 자막의 시작/끝 시간을 가진다.
- 참조 중인 자산의 삭제는 사용 장소를 알려주고 프로젝트 전반을 검토한다.
- 현재 v0.4.x 프로젝트는 수정 없이 읽을 수 있게 유지하며 명시적 사본/마이그레이션 후 v2에 쓰기 시작한다.

## 3. 필수 편집 명령과 동작

1. **가져오기/미디어 보관함**: 원본 썸네일 선택 ≠ 장면 추가, 미리보기·삭제 가능.
2. **트리밍**: 영상 시작/끝 슬라이더를 움직여 사용할 구간만 지정.
3. **분할**: 재생 헤드 위치에서 클립 둘로 나누고 오디오 기준 시간 보존.
4. **삭제/리플 삭제**: 선택 클립만 지우거나 뒤쪽 클립을 앞으로 당겨 빈 공간 제거.
5. **복제/반복**: 선택한 사진/영상 클립을 N회 삽입하며 출력 길이 실시간 갱신.
6. **순서 변경**: 터치/마우스로 클립 드래그 또는 위/아래 이동 버튼 제공.
7. **속도 변경**: 기본 0.5× ~ 2×, 원본 오디오는 피치 변화 최소화 또는 명시적 끄기.
8. **가로/세로/정사각 전환**: 16:9, 9:16, 1:1; fit/fill, crop, position 미리보기 제공.
9. **자막/텍스트**: 텍스트 클립 독립 길이, 줄바꿈, 위치, 크기, 폰트, 색상, 외곽선, 배경 투명도.
10. **음성**: 원본 오디오 보존/제거와 TTS 내레이션, 음악을 각자 별도 토글 및 음량 관리.
11. **전환/사진 움직임**: 줌, 팬, 페이드, 컷; 출력과 미리보기가 일치해야 한다.
12. **실시간 전체 재생/MP4**: 선택 클립 재생과 프로젝트 전체 재생 구별. 출력 후 브라우저 전체 시청·다운로드.

## 4. AI 보조 기능 (선택적)

- 미디어 + 사용자의 요청으로 **편집 계획 JSON** 생성; 원본을 바꾸지 않고 타임라인 후보를 표시해 확인받는다.
- 영상 분석은 처음/중간/끝 등 여러 프레임을 볼 수 있게 개선하되 지원 범위와 비용을 명시한다.
- 영상 오디오는 STT 사용자가 요청했을 때만 전사한다. 대화 없는 ASMR은 원본 소리 유지와 설명 자막만.
- 긴 영상 자동 요약/하이라이트, 반복 B-roll 제안, 비문/오타 교정, 자동 자막 싱크는 점진적으로 추가.
- AI가 생성한 대사/자막/컷 구간을 사용자가 직접 바꾸면 **재실행 시 덮어쓰지 않는다**.
- 외부 API 무료 한도·유료 전환·상업 사용 권리는 명시하며, 서버가 임의로 유료 기능에 과금 요청하지 않는다.

## 5. UI 원칙

**모바일(휴대폰 원격)**: 프로젝트 상단 → 미디어 가져오기 → 큰 플레이어 → 바로 아래 편집 도구 → 수평 스크롤 타임라인 → 자막/음성/음악 제어 → 내보내기. 편집 도구를 여러 화면 아래로 떨어뜨리지 않는다. 작은 터치 영역을 만들지 않는다.

**데스크톱**: 좌측 미디어 보관함 / 중앙 플레이어·편집 도구 / 우측 효과·속성 / 하단 넓은 다중 트랙 타임라인.

밝은 아이보리·세이지 기본 테마를 유지하고, 편집 작업에 필요한 어두운 플레이어만 대비되게 쓴다. 사용자 지정 테마는 후순위.

## 6. 단계별 개발·품질 검증

### Phase A — 비파괴 타임라인 기반 (가장 우선)
- schema v2 설계 + 레거시 읽기
- 영상 sourceIn/sourceOut 및 원본 오디오 보존
- 분할, 삭제, 복제, 반복, 드래그 순서변경
- 타임라인 길이·시작점·겹침 계산 검증
- 이미지와 MP4 혼합, 긴 영상 일부 구간 출력

### Phase B — 시각적 편집·전체 재생
- 데스크톱/모바일 양방향 편집 UI
- 영상 재생 위치와 타임라인 선택 동기화
- 오디오별 볼륨/음소거/원본 유지
- 9:16/16:9/1:1 출력, 미리보기/렌더 일치
- 자막 위치·스타일·크기·투명도 조절

### Phase C — AI 보조 / 접근성
- 사용자 요구사항 기반 컷/연출 초안 → 선택적 적용
- 로컬 CPU 기반 STT 사용 옵션과 원본 음성 보존
- 자동 컷 포인트 제안, 장면 맥락 확인, 자막 싱크
- 전체 결과/선택 구간 렌더링, 실패 복구

### 출시 기준
- 사진 광고/영상 광고/장·단편 편집/ASMR/영상 병합 **각 사례별 샘플로 자동 검증**
- 10분 원본을 30초로 트리밍해 정상 출력, 10초 영상 3회 반복시 30초 정상 출력
- 영상 원본 오디오 보존 선택 시 원본 소리가 최종 MP4에 남음
- 같은 클립을 복제/삭제해도 원본 미디어가 변하지 않음
- AI 서비스 불가해도 수동 편집 및 MP4 내보내기가 가능
- 기존 v0.4 사용자 사진·프로젝트 보존
- Windows 설치/업데이트는 ZIP 하나에 CMD 하나로 유지

## 7. 아키텍처 주의

현행 server.mjs와 public/client.js는 컷 장면 중심이다. 기존 기능을 무리하게 덧붙여서 `duration` 속성을 편집 범위로 오인하지 말 것. v2 편집 모델의 명령과 FFmpeg 그래프를 **독립 모듈**로 구현하고 테스트한 뒤 UI에 연결한다. 현재 버전을 교체하거나 사용자 데이터 파일에 직접 이행할 때는 반드시 호환성 보장.

이 문서는 개발 방향이며 **여기에 적힌 기능이 모두 구현되었다는 의미가 아니다**.
