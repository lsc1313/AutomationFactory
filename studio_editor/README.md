# Studio Editor v1.1 — AI 자동 기획 + 비파괴 영상 편집기

**사용 흐름**: 사진/동영상을 업로드 → AI 영상 초안 만들기에 원하는 요구사항 입력 → 사진과 영상 첫 프레임을 Gemini Vision이 읽고 대사·자막·장면 순서 초안 반환 → 사용자 초안 검수 → 편집기에 가져와 멘트/자막/위치/스타일/시간 수정 → FFmpeg MP4 출력.

- **AI 동영상 생성은 하지 않습니다.** 제공한 실사진/영상만 사용합니다.
- 기존 로컬 프로젝트, 저장된 비밀번호, 사진 및 MP4 파일 유지.
- **실제 이미지 분석은 Gemini API 연결 시에만 진행**됩니다. 키가 없거나 호출 오류/무료 한도를 다 쓴 경우 AI 초안을 임의로 꾸미지 않고 실패 원인을 알립니다. 무료 등급 제공 여부·상업적 이용 조건은 Google 정책에 따릅니다.
- Gemini 키를 설정하면 업로드한 이미지 축소본과 영상의 첫 프레임을 Google 서버로 전송합니다. 원본 영상 전체는 보내지 않습니다. 해당 프레임만으로 확인 불가능한 사실은 최종 사용자가 검수하세요.
- 현재 AI 음성 재생에는 설치된 Edge TTS가 필요합니다. MP4 렌더에는 FFmpeg가 필요합니다.
- PC에 Node 20+와 FFmpeg가 있으면 **동일 원클릭 설치 파일을 다시 실행하여 업데이트**합니다.

# Studio Editor — 독립 실행형 무료 로컬 영상 편집기 (v0.2)

ShortsAI, Revenue Factory, Theme Factory와 별개로 실행하는 **구독료 없는 개인용 웹 편집기**입니다. 원본 프로젝트/영상 파일은 PC에 보관합니다. **AI 초안 생성을 직접 요청하면 사진 축소본과 영상 대표 프레임이 Gemini API로 전송**되며, TTS 사용 시 대사 텍스트가 외부 음성 서비스로 전송됩니다. 자동으로 유료 AI 영상 생성을 호출하지는 않습니다. FFmpeg 및 선택적 edge-tts로 편집·출력합니다.

## 현 단계에서 실제 작동하는 기능

- Windows/PC 크롬과 같은 브라우저에서 편집, 모바일 대응 UI
- 사진(JPG/PNG/WEBP), 짧은 MP4, BGM(MP3/WAV/M4A) 업로드
- 장면 추가, 복제, 순서 변경, 삭제, 길이 설정
- 장면별 대본·자막 직접 수정, 4가지 자막 스타일, 상·중·하 배치
- 사진 줌/팬 및 원본 사진 기반 블러 배경, 영상 클립 조합
- 음성 없음 또는 한국어 여성/남성 TTS 선택(별도 edge-tts 설치 시)
- 배경음악 파일 선택·음량 조절, 720×1280 세로 MP4 내보내기
- 프로젝트 자동 저장이 아닌 **저장 버튼** 방식 (출력 시 저장), 여러 프로젝트 보관
- 로컬에서 처음 실행 시 12자 이상 관리 비밀번호 생성, 쿠키 및 CSRF로 API 보호
- 기존 프로젝트 코드와 섞이지 않는 독립 실행 구조

## Windows 시작

1. [Node.js 20+](https://nodejs.org)와 [FFmpeg](https://ffmpeg.org/) 및 FFprobe 설치 후 PATH 등록
2. `windows/start-hidden.vbs` 더블클릭. 검은 콘솔 없이 크롬 브라우저가 열립니다.
3. `http://127.0.0.1:8050/app`에서 **최초 관리자 비밀번호** 설정
4. 사진 또는 영상 등록 → 타임라인 편집 → 저장 → MP4 내보내기
5. 한국어 AI 음성을 사용하려면 `python -m pip install edge-tts` 후 `edge-tts --help` 확인. 설치/서비스 미연결 시 음성 생성은 실패하며 무음 설정으로 MP4 제작 가능.

작업 데이터는 `studio_editor/private`에 저장됩니다. 절대로 GitHub에 업로드하지 마세요. 폴더 교체 때 `private`는 유지하세요.

## 휴대폰 연결 (기존 Tailscale 활용)

기존 Revenue Factory(8443)와 쇼츠스튜디오(443)를 건드리지 않도록 **Tailscale Serve 10000** 포트를 별도로 사용합니다.

- PC와 휴대폰의 Tailscale이 이미 켜져 있어야 합니다.
- 관리자 PowerShell에서 `windows/enable-phone.ps1` 실행 (기존 Serve를 덮어쓰지 않음)
- 설정이 성공하면 `https://<PC DNS 이름>:10000/app` 주소 출력
- `windows/start-hidden.vbs`로 에디터를 재시작한 후 모바일에서 접속
- 공유하는 Tailscale 기기도 접속할 수 있으므로 관리자 비밀번호를 외부에 공개하지 마세요. Funnel/포트포워딩은 사용하지 않습니다.

PC가 켜져 있어야 서버에서 렌더링을 진행합니다. 현재 모바일은 컷 기반 간편 편집 UI를 제공합니다. PC의 다중 트랙 파형 드래그 편집, 음성 단어별 싱크 자동 정렬, 화자 분리, AI 이미지 이해, 복잡한 전환 효과는 **아직 제공하지 않습니다**. 기존 브루 전체 기능을 구현한 제품이라고 주장하지 않습니다.

## 기술/비용/저작권

- Node.js 기본 내장 모듈 + FFmpeg (별도 npm 설치 불필요)
- 별도 AI 영상 GPU, SaaS 구독비 불필요
- FFmpeg/사용 라이브러리의 라이선스 및 생성 영상에 사용할 음원 저작권을 준수하세요.
- Edge TTS는 외부 음성 서비스에 대본을 전송하며 서비스 정책, 가용성·상업적 이용 조건을 별도 확인해야 합니다. 완전히 오프라인인 구성은 무음 또는 사용자가 업로드한 원본 동영상/음악만 활용합니다.

## 휴대폰 원격 조작을 위한 한 번 설치/업데이트 (v0.2.1)

가능하면 ZIP 파일을 풀고 여러 스크립트를 실행하는 대신 **한 번만** 아래 PowerShell 명령어를 실행하세요. 설치 파일을 자동 다운로드하고, 기존 저장된 프로젝트/업로드 파일은 보존하며, PC 바탕화면에 `Studio Editor` 바로가기를 생성합니다. 다음부터는 바로가기만 클릭하세요. 기존 Shorts Studio(443), Revenue Factory(8443)는 건드리지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/lsc1313/AutomationFactory/feature/standalone-studio-editor-v0-1/studio_editor/windows/install-oneclick.ps1').Content))"
```

선택: ZIP 안의 `windows/Install-StudioEditor.cmd`를 더블클릭하는 방법도 있습니다. 설치·업데이트 모두 같은 실행으로 처리합니다. 설치 위치는 `%LOCALAPPDATA%\StudioEditor`, 실행 주소는 `http://127.0.0.1:8050/app`이고, Tailscale이 활성화되어 있다면 휴대폰용 HTTPS 10000 연결도 시도합니다. 첫 실행에는 PC에서 관리자 비밀번호를 1회 설정하세요. Node.js 20+는 필요하고, FFmpeg/FFprobe가 없으면 영상 출력만 비활성화됩니다. 오류가 날 경우 `%TEMP%\StudioEditor-install.log`를 확인하세요.
## 2026-11-17 Gemini 모델 갱신
AI 초안은 API 키로 `models.list`를 먼저 호출해 실제 `generateContent` 가능한 모델을 확인한 뒤 `gemini-3.5-flash-lite`를 우선 사용합니다. 모델 404/미지원 시 `gemini-3.8-flash` 등 사용 가능한 모델로 넘어갑니다. 구형 `gemini-2.5-flash-lite` 고정값을 제거했습니다. 무료 한도 초과(429)는 다른 유료 모델로 우회하지 않고 명확한 오류를 반환합니다.

# v1.1 통합 기능 (2026-11-17)

**기존 AI 기획 및 대본·자막·목소리·BGM 자동 초안 기능은 삭제되지 않았습니다.** AI 초안 작성 후 동일한 프로젝트에서 정밀 타임라인을 수정할 수 있습니다. AI가 선택한 사진과 영상도 수동으로 교체·중복·분할할 수 있습니다.

## 주요 작업 기능
- **비파괴 편집:** 사진, MP4 원본은 그대로 두고 타임라인의 클립 범위만 편집. v0.4 프로젝트는 읽고 저장 시 v2로 전환하며 이전 프로젝트 백업을 private/backups에 생성
- **길이 조절:** 영상 원본 시작·끝 자르기, 재생헤드 분할, 클립 삭제/복제/반복(최대 40회), 위치 변경, 0.5~2배 재생 속도
- **합성:** 이미지·영상 혼합, 줌·이동, 일반 컷 및 간단 페이드, 전체 영상 출력/재생/다운로드
- **규격:** 세로 9:16 / 가로 16:9 / 정사각형 1:1, fit/fill, CPU 기반 720p H.264 MP4
- **오디오:** 촬영 원본 소리 유지/무음/TTS 내레이션/원본+내레이션, 소스 음량, 전체 BGM, 시간 지정 가능한 추가 음악·효과음 트랙
- **자막:** 클립별 대사·자막 및 독립 시간 지정 자막 트랙, 색상·글꼴·크기·외곽선·위치·타이밍 변경, 투명 배경
- **로컬 음성 인식:** 선택한 영상 클립에서 CPU용 Whisper tiny 기반 음성→시간별 자막 초안(첫 실행에 모델 다운로드/인터넷 필요). ASMR처럼 음성이 없는 영상에는 사용하지 않아도 됩니다
- **모바일/PC:** 타임라인 선택/순서 변경, 모바일 버튼과 PC 드래그, 실행 취소·다시 실행, 원본 미디어 선택·삭제 안전장치
- **AI 분석 개선:** 선택한 영상의 여러 대표 프레임을 보고 초안을 만들며, 필요시 원본 영상 일부 구간을 제안. 영상 전체 내용·음성을 완전히 알고 있다고 주장하지 않습니다
- **업로드:** 스트리밍으로 최대 1GB 입력, 범위 요청(HTTP 206)으로 원본 및 출력 MP4 재생

## 권장 사용법
1. 사진·영상(필요하면 음악)을 업로드합니다.
2. AI 기획이 필요하면 요구사항·스타일·목소리·BGM을 선택하고 **AI 영상 초안 생성**을 누릅니다. 직접 편집하려면 AI를 사용하지 않고 사진/영상 선택 후 장면을 추가합니다.
3. 화면 아래 **정밀 타임라인 편집**에서 컷·속도·반복·소리·자막·비율을 수정하고 필요시 독립 자막/효과음을 배치합니다.
4. **전체 영상 제작·보기**로 실제 출력 결과를 검증하고 다운로드합니다.

## 환경 및 제한
- GPU·유료 영상 생성 API는 필요하지 않습니다. 외부 Gemini API 무료 한도 및 Edge TTS 서비스 가용성은 보장되지 않습니다.
- 음성 인식용 faster-whisper는 선택적으로 설치되며 CPU 작업과 최초 모델 다운로드가 필요합니다. 비설치여도 수동 편집과 AI 기획/FFmpeg는 사용할 수 있습니다.
- 이 버전은 실제 작동하는 웹 편집기이지만 **CapCut/Vrew 전체 기능 복제품은 아닙니다**. 파형을 픽셀 단위로 편집하는 데스크톱 NLE, 모션 그래픽 키프레임, 고급 색보정, 화자 분리/단어 단위 타이밍, 실시간 모든 효과 프리뷰는 제공하지 않습니다. 전체 미리보기는 FFmpeg로 출력한 영상을 재생하는 방식입니다.
- 길이 제한: 전체 60분, 클립 160개, 1회 업로드 1GB. 저사양 PC에서 긴 영상은 렌더링 시간이 오래 걸릴 수 있습니다.
- 기존 앱/포트/메인 브랜치는 변경하지 않고 독립적으로 설치합니다.
