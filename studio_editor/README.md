## Studio Editor v1.5.3 — 네이버 블로그로 옮기기
- 블로그 편집기의 **네이버 블로그로 옮기기**에서 제목, 본문 전체, 태그를 각각 복사합니다.
- **본문 전체 복사**는 사진 위치 표시를 포함한 일반 텍스트이며, 빠른 글 작성용입니다.
- 글과 사진을 번갈아 게시하려면 작성 순서별 단계를 따라 문단을 복사하고, 사진 파일을 하나씩 다운로드하여 스마트에디터 ONE의 사진 메뉴로 등록합니다. 사진 설명도 별도 복사할 수 있습니다.
- 원본 사진은 내려받은 뒤 네이버 편집기에서 크기·정렬을 맞춰야 합니다. Studio Editor의 HTML 서식이 네이버에 그대로 적용된다고 보장하지 않습니다.
- 네이버 글쓰기 링크는 사용자의 브라우저에서 열리며, 자동 로그인·자동 게시·비밀번호 수집은 없습니다. 발행은 네이버에서 직접 진행합니다.

## Studio Editor v1.5.2 — 블로그 사진 크기·정렬·여백
블로그 사진 블록마다 크기를 20~100%(5% 단위), 왼쪽/가운데/오른쪽 정렬, 위아래 여백을 지정할 수 있습니다. 기본 사진 크기는 본문 폭의 65%이고, 이전에 저장한 사진에는 이 기본값이 적용됩니다. 설정은 저장·재열기·미리보기·독립 HTML 내보내기에서 유지합니다. 원본 사진 파일은 변경하지 않습니다. Markdown 내보내기는 사진의 배치 서식을 지원하지 않습니다.

# Studio Editor v1.5.0 — 영상 편집기 + 블로그 편집기

하나의 로그인 계정에서 **영상 편집기**와 **블로그 편집기**를 선택하는 시험판입니다. 기존 영상 기능과 기존 프로젝트를 보존합니다.

## 블로그 편집기 기능
- 글 제목·소개·분류·태그·작성 상태 관리
- 본문 문단·큰 제목·소제목·목록·인용·구분선·업로드 사진 블록 추가, 순서 변경 및 삭제
- 본문 미리보기, 글 저장·불러오기·삭제
- 사진을 포함하는 **독립형 HTML** 파일과 Markdown 원고 내보내기 (자동 블로그 플랫폼 게시 기능은 아직 없음)
- 등록된 Gemini 키로 **AI 초안 작성**. 실제 Gemini 응답을 사용하며 사실 검토 후 저장 필요
- 회원별 블로그 글과 사진 소유권 검사. 다른 계정의 원고/사진에 접근 불가
- 휴대폰·태블릿 대응 UI

## 사용
1. `windows/Install-StudioEditor.cmd`로 업데이트하고 로그인합니다.
2. 화면 상단에서 `🎬 영상 편집기` 또는 `✍️ 블로그 편집기`를 고릅니다.
3. 블로그 편집기에서 새 글 → 제목·본문·사진 → 미리보기 → 저장 또는 파일 내보내기를 실행합니다.
4. AI 초안은 영상 편집기에서 Gemini 키를 등록한 뒤 블로그 편집기에 주제와 사실을 입력하면 사용합니다.

**주의:** 아직 PC에서 실행되는 계정형 시험판이며 완전한 공개 SaaS로 배포된 상태는 아닙니다. 블로그 플랫폼 자동 발행, 포스팅 예약, 이메일 인증, 결제는 구현하지 않았습니다.

# Studio Editor v1.4.0 — 계정형 AI 영상 편집 시험판

## 현재 시험판의 범위
Studio Editor는 PC에서 실행되는 Node.js + FFmpeg 기반 영상 편집기입니다. 이번 버전은 **기존 체험 링크 기능을 제거**하고 회원가입/로그인 및 계정별 프로젝트·미디어·출력 저장을 지원합니다.

**중요:** 이 빌드는 아직 공개 도메인에 배포된 SaaS가 아닙니다. 실행 서버는 사용자의 PC에 있으며, 이미 설정한 휴대폰용 Tailscale HTTPS 주소 또는 PC의 `http://127.0.0.1:8050/app`에서 계정형 사용을 시험합니다. PC를 끄면 접근할 수 없습니다. 공개 서버, 이메일 검증, 비밀번호 초기화, 결제는 추후 결정합니다.

## 사용법
1. Windows에서 `windows/Install-StudioEditor.cmd`를 실행합니다. 바탕화면 바로가기를 이용해 실행할 수 있습니다.
2. 브라우저에서 **회원가입**을 선택하고 이메일·12자 이상 비밀번호를 입력합니다. 로그인 상태로 바로 편집기를 엽니다.
3. 로그인 후 미디어 업로드 → AI 기획(선택) → 영상 편집·자막·음성 → 저장 → MP4 출력 순서로 사용합니다.
4. 로그아웃 후 같은 이메일과 비밀번호로 다시 로그인하면 계정별 작업을 이어서 볼 수 있습니다.
5. 이전 버전에서 만든 프로젝트는 **기존 관리자 계정**에 남아 있습니다. 이메일을 `owner`로 입력하거나 비워두고 기존 비밀번호로 로그인하면 접근할 수 있습니다. 회원가입으로 만든 새 계정에는 기존 관리자 작업이 자동으로 복사되지 않습니다.

## 데이터 저장 및 보안
- PC 로컬 설치 폴더의 `private/`는 업데이트 시 보존합니다. 기존 관리자 프로젝트·미디어는 기존 위치를 사용합니다.
- 신규 계정은 `private/users/<서버에서 생성한 계정 ID>/` 아래에 프로젝트·미디어·출력 파일을 분리합니다.
- 비밀번호는 scrypt 해시로 저장하고, 세션 쿠키는 HttpOnly/SameSite이며 변경 API는 CSRF 검사를 합니다.
- 개인정보·소스 파일을 GitHub에 올리지 마세요. `private/`과 API 키는 공유하지 마세요.
- **이메일 인증·계정 복구·결제·상용 SaaS 운영을 아직 구현하지 않았습니다.** 불특정 다수에게 공개하지 않고 소수 테스트 용도로만 사용하세요.
- Gemini 키는 계정별 설정 파일에 저장됩니다. AI 분석 요청은 선택한 외부 AI 서비스에 전송될 수 있습니다. 음성 TTS에도 외부 서비스가 이용될 수 있습니다.

## 기능
사진·영상·음원 업로드, 장면 구성, AI 영상 기획, 사진/영상 효과, 자막·타임라인·음성 편집, FFmpeg MP4 출력. PC와 모바일에 맞춘 편집 UI를 제공합니다.

## 설치 환경
Windows, Node.js 20+, FFmpeg/FFprobe 권장. 선택적으로 Python 및 edge-tts 사용. 설치 프로그램은 GitHub 작업 브랜치의 검증된 파일을 받아 설치하고 기존 작업 폴더는 삭제하지 않습니다.

## 자동 검사
`node --test tests/*.test.mjs`
`node tests/browser-smoke.mjs` (Chrome 또는 Chromium 및 FFmpeg 필요)

## 차후 SaaS 전환 항목 (아직 미구현)
중앙 호스팅, HTTPS 공개 도메인, 검증 가능한 이메일 가입/비밀번호 재설정, 사용자별 서버 렌더링 대기열·쿼터, 안전한 영구 스토리지, 결제 및 운영/관리자 기능.
